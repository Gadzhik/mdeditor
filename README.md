# MD Editor

Быстрый Markdown-редактор и ридер, работающий в браузере: слева текст, справа живое превью. Умеет также читать PDF.
Работает локально, без серверов в интернете. Файлы читаются и пишутся прямо на вашем диске.

## Установка и запуск

**Требования**
- [Node.js](https://nodejs.org) 20 или новее (проверить: `node -v`)
- Браузер на Chromium: Chromium, Chrome, Brave, Edge или Vivaldi. В Firefox тоже работает, но с ограничениями (см. [Поддержка браузеров](#поддержка-браузеров)).

Отдельно устанавливать ничего не нужно. Для запуска в папке приложения есть файл **`mdeditor`**:

```sh
cd /путь/к/mdeditor
./mdeditor
```

При первом запуске он сам установит зависимости и соберёт приложение, поэтому первый запуск займёт некоторое время. Дальше он мгновенный. Скрипт:
- пересобирает приложение, только если исходники изменились;
- поднимает локальный сервер в фоне, если он ещё не запущен;
- открывает редактор в отдельном окне без вкладок и адресной строки (режим `--app` Chromium-браузера). Если такого браузера нет, адрес откроется в браузере по умолчанию.

Сервер продолжает работать после закрытия окна, поэтому следующий запуск открывается сразу. Он почти не потребляет ресурсов. Остановить его: `./mdeditor stop`.

Если хотите открыть редактор в своём браузере, запустите `./mdeditor serve` и откройте показанный адрес (`http://localhost:4317/`).

### Все команды

```
./mdeditor            собрать (если нужно), запустить сервер и открыть окно редактора
./mdeditor serve      только запустить сервер и вывести адрес
./mdeditor stop       остановить фоновый сервер
./mdeditor status     показать, запущен ли сервер
./mdeditor install    (необязательно) ярлык в меню приложений и команда mdeditor
./mdeditor uninstall  убрать ярлык и команду
```

Порт по умолчанию `4317`, другой можно задать так: `MDEDITOR_PORT=5000 ./mdeditor`.

### Ярлык в меню (необязательно)

Если хотите запускать редактор из меню приложений, а не из папки, выполните `./mdeditor install`. Команда добавит ярлык **MD Editor** с иконкой (`~/.local/share/applications/mdeditor.desktop`) и команду `mdeditor` в `~/.local/bin`, которую можно запускать из любого терминала. Ярлык ссылается на текущее расположение папки, поэтому после переноса папки команду нужно повторить. Убрать ярлык: `./mdeditor uninstall`.

## Использование

### Интерфейс

```
┌──────────────────────────────────────────────────────────────────────┐
│ ☰  Новый  Открыть  Папка  Сохранить  ● notes/todo.md   Редактор|Split|Чтение ↔ ◐│
├──────────┬──────────────────────────┬────────────────────────────────┤
│ дерево   │ редактор (исходный текст)│ превью                         │
│ папки    │                          │                                │
└──────────┴──────────────────────────┴────────────────────────────────┘
```

- **☰** показывает или скрывает боковую панель с деревом папки.
- **●** перед именем файла означает, что есть несохранённые изменения.
- Справа на панели показано число слов и строк.
- **Редактор / Split / Чтение** переключают режим: только текст, текст и превью, только превью (удобно для чтения).
- **100%** показывает масштаб текста заметки. Клик возвращает 100%.
- **↔** настраивает ширину текста в превью: ползунок от 500 до 2000 px или галочка «Во всю ширину». Двойной клик по ползунку возвращает 1200 px. Настройка запоминается.
- **◐** переключает тему по кругу: авто (как в системе), светлая, тёмная.
- Разделитель между редактором и превью можно перетаскивать мышью. Двойной клик возвращает 50/50.

Прокрутка редактора и превью синхронизирована: листаете одно, другое следует за ним.

### Работа с файлами

| Действие | Как |
|---|---|
| Открыть файл | **Открыть** или `Ctrl+O` (markdown или PDF) |
| Сохранить | **Сохранить** или `Ctrl+S`. Изменения записываются прямо в исходный файл на диске |
| Сохранить как | `Ctrl+Shift+S` |
| Новый документ | **Новый** |
| Открыть перетаскиванием | Перетащите `.md` или `.pdf` файл (или папку) в окно |

При первой записи в файл браузер спросит разрешение на редактирование. Это нормально, разрешите.

Если в документе есть несохранённые изменения, перед открытием другого файла редактор спросит подтверждение.

### Работа с папкой (заметки, документация)

1. Нажмите **Папка** и выберите каталог (или перетащите его в окно).
2. Слева появится дерево всех `.md` и `.pdf` файлов (у PDF метка «PDF»). Служебные папки (`node_modules`, `.git`, скрытые) пропускаются.
3. Кликните по файлу, чтобы открыть его.

Когда открыта папка:
- **картинки** с относительными путями (`![](../img/pic.png)`) показываются в превью;
- **ссылки** на другие заметки (`[гайд](docs/guide.md)`) открываются в редакторе по клику, ссылки на PDF (`[книга](books/book.pdf)`) открываются в читалке.

Папка запоминается между запусками. После перезапуска браузера может появиться кнопка **«Восстановить доступ»**: нажмите её, чтобы снова дать разрешение (так требует браузер).

### Положение и масштаб

Для каждой заметки запоминаются место, на котором вы остановились (в любом режиме, в том числе в режиме чтения), позиция курсора и масштаб текста. При следующем открытии файла всё восстанавливается. Файл узнаётся даже после переименования (в Chromium).

Масштаб текста меняется через `Ctrl+=` / `Ctrl+−`, `Ctrl+колесо мыши` или сбрасывается `Ctrl+0`. Он действует на редактор и превью, а масштаб окна браузера не трогает. Новые заметки открываются с последним выставленным масштабом.

При переключении режимов (Редактор / Split / Чтение) видимое место остаётся на экране.

### Черновик

Текст сохраняется в браузере автоматически через полсекунды после каждой правки и восстанавливается при следующем запуске вместе с позицией курсора. Даже несохранённый документ не потеряется при закрытии окна.

Черновик хранится только в этом браузере и не заменяет сохранение в файл.

### Что поддерживает превью

- Заголовки, списки, цитаты, ссылки, картинки, таблицы, горизонтальные линии
- Списки задач: `- [ ]` и `- [x]`
- Блоки кода с подсветкой: js, ts, python, bash, json, css, html, yaml, rust, go, java, kotlin, c, cpp, c#, php, ruby, swift, lua, sql, diff, dockerfile, ini/toml, makefile, nginx
- Автоматические ссылки из адресов `https://…`
- HTML внутри markdown (небезопасные теги и скрипты вырезаются)

## Чтение PDF

PDF открывается так же, как заметки: через **Открыть** (`Ctrl+O`), из дерева папки, по ссылке из заметки или перетаскиванием. Вместо редактора появляется читалка со своей панелью:

| Элемент | Что делает |
|---|---|
| **Панель** | Показывает или скрывает левую панель с двумя вкладками. **Страницы**: миниатюры всех страниц, текущая подсвечена, клик переходит к странице. **Оглавление**: закладки PDF, клик переходит к разделу. Выбранная вкладка запоминается; если в файле нет оглавления, открывается «Страницы» |
| **N / M** | Текущая страница из общего числа. Введите номер и нажмите `Enter`, чтобы перейти |
| **− / масштаб / +** | Масштаб: «По ширине», «Страница целиком» или проценты. `Ctrl+колесо мыши` масштабирует относительно курсора |
| **Поиск** | Ищет по всему документу, подсвечивает все совпадения и показывает «текущее / всего». `Enter` переходит к следующему, `Shift+Enter` к предыдущему, `Esc` сбрасывает поиск |
| **◑** | Только в тёмной теме: инвертирует страницы, чтобы белый лист не слепил. Повторное нажатие возвращает исходные цвета |
| **✕** | Закрывает PDF и возвращает к заметке |

- **Текст можно выделять и копировать**, как на обычной странице.
- **Позиция запоминается** для каждого PDF: страница, место на ней и масштаб. При следующем открытии этого же файла чтение продолжится с того же места, даже если файл переименован.
- **Новый PDF** открывается с последним масштабом, который вы выставляли (по умолчанию «По ширине»).
- **Последний PDF открывается снова** при перезапуске, если он был открыт через **Открыть**, из папки или перетаскиванием в Chromium. Если браузер забыл разрешение, откроется заметка.
- **Черновик заметки не трогается**: PDF открывается поверх, а **✕** или клик по заметке в дереве возвращает к ней без потерь.
- PDF с паролем: читалка попросит ввести пароль.
- Большие PDF открываются быстро: страницы и миниатюры рисуются только по мере прокрутки.

PDF доступен только для чтения: аннотации и правка не поддерживаются.

## Заметки к тексту

К любому фрагменту заметки или PDF можно прикрепить заметку.

1. Выделите текст: в превью, в редакторе или в PDF.
2. Нажмите появившуюся рядом кнопку **＋ Заметка** (или `Alt+N`).
3. Напишите текст и нажмите **Сохранить** (`Ctrl+Enter`). Текст можно оставить пустым, тогда фрагмент просто останется подсвеченным.

Фрагменты с заметками подсвечиваются жёлтым. Клик по подсветке в превью или PDF открывает заметку для правки или удаления. В редакторе текст заметки виден во всплывающей подсказке при наведении.

Кнопка **Заметки** на панели (с числом заметок) открывает справа список всех заметок документа по порядку их мест в тексте. Клик по заметке ведёт к фрагменту и ненадолго выделяет его. Кнопки **Изменить** и **Удалить** появляются при наведении.

**Экспорт в Markdown.** Кнопка **Экспорт** в шапке панели заметок:
- **Сохранить в файл .md**: сохраняет `<документ>.notes.md` (для `doc.md` это `doc.notes.md`, для `book.pdf` это `book.pdf.notes.md`). В Firefox файл скачивается;
- **Скопировать как Markdown**: в буфер обмена, например чтобы вставить в другую заметку;
- **Открыть в редакторе**: как новый несохранённый документ, его можно дописать и сохранить через `Ctrl+S`.

В экспорт попадают все заметки документа в порядке их мест в тексте: место (стр. N или строка N), цитата, текст заметки и дата. Заметки с удалённым фрагментом помечены.

**Где хранятся.** Если документ лежит в открытой папке, заметки сохраняются в файл рядом с ним: для `book.pdf` это `book.pdf.notes.json`, для `doc.md` это `doc.md.notes.json`. Их можно хранить, копировать и синхронизировать вместе с документами. Если папка не открыта, заметки хранятся в браузере. Как только вы откроете папку с этим документом, они перенесутся в файл при следующем изменении. Внизу панели написано, где лежат заметки текущего документа.

**Правка текста.** В markdown заметка привязана к самому фрагменту, а не к номеру строки. Если вы дописываете или удаляете текст вокруг, заметка остаётся на своём фрагменте. Если удалить фрагмент целиком, заметка не пропадёт: в списке она будет помечена «фрагмент не найден». Выделять можно и в превью, и в редакторе: `**жирный** текст` в исходнике и «жирный текст» в превью считаются одним и тем же фрагментом.

## Горячие клавиши

**Общие**

| Клавиши | Действие |
|---|---|
| `Ctrl+O` | Открыть файл |
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как |
| `Alt+1` / `Alt+2` / `Alt+3` | Редактор / Split / Чтение |
| `Ctrl+\` | Боковая панель |
| `Alt+[` / `Alt+]` | Текст в превью уже / шире (шаг 100 px) |
| `Ctrl+=` / `Ctrl+−` / `Ctrl+0` | Масштаб текста заметки: больше / меньше / 100% |
| `Ctrl+колесо` | Масштаб текста заметки |
| `Alt+N` | Заметка к выделенному фрагменту (и в PDF) |
| `Ctrl+Enter` / `Esc` | Сохранить / закрыть заметку (в окне заметки) |
| `Ctrl+B` / `Ctrl+I` | Жирный / курсив (повторное нажатие снимает) |
| `Ctrl+F` | Поиск и замена |
| `Ctrl+Z` / `Ctrl+Shift+Z` | Отменить / повторить |
| `Tab` / `Shift+Tab` | Отступ / убрать отступ |

**В читалке PDF**

| Клавиши | Действие |
|---|---|
| `Ctrl+F` | Поиск по PDF |
| `Enter` / `Shift+Enter` | Следующее / предыдущее совпадение (в поле поиска) |
| `Esc` | Сбросить поиск |
| `Ctrl+=` / `Ctrl+−` | Увеличить / уменьшить |
| `Ctrl+0` | Масштаб по ширине |
| `Ctrl+колесо` | Масштаб относительно курсора |
| `PageUp` / `PageDown`, стрелки | Прокрутка страниц |

На macOS вместо `Ctrl` используется `Cmd`.

## Поддержка браузеров

| Возможность | Chromium, Chrome, Edge, Brave | Firefox, Safari |
|---|---|---|
| Редактор, превью, черновик | ✓ | ✓ |
| `Ctrl+S` пишет прямо в файл на диске | ✓ | ✗ файл скачивается |
| Открытие папки и дерево | ✓ | ✗ |
| Чтение PDF | ✓ | ✓ |
| Повторное открытие последнего PDF при запуске | ✓ | ✗ |
| Окно без вкладок (ярлык) | ✓ | ✗ открывается вкладка |

Причина в том, что прямой доступ к файлам (File System Access API) пока есть только в Chromium-браузерах.

## Решение проблем

**Не запускается двойным кликом в файловом менеджере.** Многие файловые менеджеры открывают скрипты в текстовом редакторе. Запустите из терминала (`./mdeditor`) или включите в настройках файлового менеджера запуск исполняемых файлов.

**Ярлык не появился в меню.** Перезапустите лаунчер или выйдите и войдите в сессию. Проверьте, что файл существует: `ls ~/.local/share/applications/mdeditor.desktop`.

**`mdeditor: command not found`.** Папка `~/.local/bin` не добавлена в `PATH`. Добавьте в `~/.bashrc` или `~/.zshrc` строку `export PATH="$HOME/.local/bin:$PATH"` либо запускайте `./mdeditor` из папки проекта (так работает и без `install`).

**«порт 4317 занят другим приложением».** Запустите на другом порту: `MDEDITOR_PORT=4318 mdeditor`.

**«сервер не запустился».** Посмотрите лог: `$XDG_RUNTIME_DIR/mdeditor-$USER/server.log`.

**Проект лежит на съёмном диске.** Ярлык работает, только когда диск смонтирован по тому же пути.

**Черновик сменился на старый текст.** Черновик привязан к браузеру и адресу. Если открыть редактор на другом порту или в другом браузере, черновик будет свой.

**После обновления кода ничего не изменилось.** Скрипт пересобирает приложение при запуске, но работающая страница остаётся старой. Перезагрузите окно (`Ctrl+R`).

## Для разработчиков

```sh
npm install
npm run dev      # dev-сервер с горячей перезагрузкой
npm run build    # проверка типов и сборка в dist/
```

Сборка в `dist/` — это обычная статика, её можно раздавать любым веб-сервером.

**Структура**

| Файл | Назначение |
|---|---|
| `mdeditor` | Скрипт запуска и установки ярлыка |
| `src/main.ts` | Интерфейс, состояние документа, горячие клавиши, drag & drop |
| `src/editor.ts` | Редактор на CodeMirror 6 |
| `src/md.worker.ts` | Парсинг markdown в Web Worker (markdown-it + highlight.js) |
| `src/preview.ts` | Санитизация (DOMPurify) и инкрементальное обновление превью |
| `src/scrollsync.ts` | Синхронный скролл редактора и превью |
| `src/files.ts` | Открытие и сохранение файлов (File System Access API + fallback) |
| `src/tree.ts` | Дерево папки, резолв относительных путей |
| `src/pdf.ts` | Читалка PDF на pdf.js (загружается лениво, при первом открытии PDF) |
| `src/notes.ts` | Заметки к тексту: модель, хранение (`*.notes.json` или браузер), панель и окно заметки |
| `src/anchor.ts` | Привязка заметок к тексту markdown: поиск цитаты в исходнике и превью |
| `src/storage.ts` | IndexedDB: черновик и сохранённые доступы к файлам |
| `src/theme.ts`, `src/styles.css` | Темы и стили |

**Как устроена скорость**

- Парсинг markdown идёт в Web Worker, поэтому набор текста не блокируется даже на файлах в мегабайты.
- Превью делится на блоки, и в DOM заменяются только изменившиеся.
- `content-visibility: auto`: браузер не раскладывает блоки вне экрана.
- Синхронный скролл находит позицию бинарным поиском, не обходя весь документ.
- Языки подсветки кода загружаются только при первой встрече.
- pdf.js (~1 МБ) и его воркер загружаются только при первом открытии PDF, стартовая загрузка редактора от этого не растёт. Страницы PDF рисуются лениво, только видимые.
- Ресурсы pdf.js (cmaps для CJK, стандартные шрифты, wasm-декодеры) отдаются по адресу `/pdfjs/` плагином в `vite.config.ts`.
